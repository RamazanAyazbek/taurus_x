TAURUS SHORT v7.3 — отчёт о проверках ZIP (06.11.2026)
==================================================

Исходный архив: Short_v4.1(1).zip (SHA-256 совпадает с Short_v4.1.zip).
Оригинальные config.py, main.py, backtester.py, exit_logic.py,
signal_logic.py, log_parser.py, reporter.py и требования Python
сохранены без изменения. В market_data.py добавлено поле 1m open.

1) Проверка компиляции всех .py:
   python -m compileall -q *.py
   ПРОЙДЕНО.

2) Полностью автономный набор тестов:
   python self_test.py
   8 тестов, 8 PASSED. Проверены:
   - разбор реальной зоны S1, отсутствие поддержки и пробитый S1;
   - отсутствие использования будущих мониторных строк;
   - Taker Buy 20-минутной давности;
   - отсутствие фальшивого входа при пропущенной 1m свече;
   - загрузчик 1m корректно возвращает open/high/low/close;
   - кеш одной свечной выборки на пять сценариев;
   - полный прогон всех 5 режимов на синтетических 1m свечах;
   - реальная запись 06.11 19:30: близкая S1 (0.2678%),
     рост Taker Buy +7.7 процентных пункта.

3) Дополнительный smoke-test на реальных наблюдениях Collector
   от 06.11 12:00, но с искусственными будущими 1m свечами.
   В каждом из 5 режимов обнаружен 06.11 19:20 SHORT.
   Условный размер: baseline=1.0, support=0.5, taker=0.5,
   preentry=0.5, combined=0.25. Синтетические TP/SL не
   являются историческими результатами.

4) Автономная предварительная оценка 15 старых закрытых сделок:
   python offline_historical_audit.py
   baseline +12.7000 pp; support +13.1850 pp;
   taker +11.2400 pp; support+taker +11.5250 pp.
   S1 затронул 4 из 15, Taker рост затронул 4 из 15.
   06.11 отсутствует в исходном CSV и не включён.
   Тест preentry нельзя рассчитать без реальных Binance 1m.
   Это только рескоринг размеров по сохранённым исходам,
   а НЕ новый полноценный бэктест, НЕ equity, НЕ доход на маржу.

5) Ограничение среды, в которой подготовлен ZIP:
   Интернет/DNS в Python-контейнере недоступен (ошибка
   Temporary failure in name resolution при запросе к
   fapi.binance.com). Поэтому ПОЛНЫЙ исторический запрос к
   Binance Futures 1m и полный новый PnL здесь НЕ выполнены.
   Для этого предусмотрен обычный локальный запуск:
     python run_experiments.py

6) Известные неустранённые ограничения исходной v7.3:
   - неполные сделки не попадают в CSV (по запросу пока оставлено);
   - exit_logic игнорирует первую минутную свечу;
   - реалистичный live fill, funding и квантование лота не моделируются;
   - гипотетический вход с 3-минутной задержкой ≠ фактический fill;
   - изменение условного размера позиции не меняет Win Rate.

Рекомендуем сравнивать количество завершённых сделок, состав
сигналов и обе суммы Net PnL, а не только TP/(TP+SL).
