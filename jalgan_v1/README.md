# Taurus Backtest V5.7 — experimental filters + BE

Запуск из каталога проекта:

```bash
python main.py
```

Все параметры и переключатели находятся в `config.py`.

## Изменения V5.7

1. `CURRENT_VOLUME_XMED_MIN = 1.8` — новый порог проекции объёма.
2. `ENABLE_SHORT_TERM_MOMENTUM_FILTER = True` — LONG разрешён только если цена выросла за недавний интервал. Расчёт идёт из фактических цен лога, не из `dPrice`: `dPrice` в логе измеряется от начала часа.
3. `ENABLE_R1_BREAKOUT_RETEST_FILTER = True` — если текущая запись помечена как R1, LONG допускается только после обнаруженного в истории выхода выше верхней границы R1 и ретеста в пределах `R1_RETEST_TOLERANCE_PCT`. Вне R1 этот фильтр не блокирует сигнал.
4. `BE_PCT = 1.1` теперь реально моделируется: когда цена достигает +1.1% в пользу позиции, стоп переносится к цене входа и начинает действовать со следующей 1m-свечи. Это консервативно обходит неопределённость порядка high/low внутри одной свечи.
5. В CSV добавлены `entry_vol_xmed`, контекст доходности за 30m/2h/4h и краткосрочный momentum.
6. Исправлен `get_previous_return()`: функция больше не использует последнюю строку всего файла для исторического расчёта.

## Как изолированно тестировать фильтры

Для сравнения включай/выключай по одному параметру в `config.py` и каждый раз сохраняй результат в отдельный CSV:

- Только новый порог объёма: `ENABLE_SHORT_TERM_MOMENTUM_FILTER=False`, `ENABLE_R1_BREAKOUT_RETEST_FILTER=False`, `BE_PCT=0.0` (для baseline без BE).
- Momentum: включить `ENABLE_SHORT_TERM_MOMENTUM_FILTER=True`.
- R1: включить `ENABLE_R1_BREAKOUT_RETEST_FILTER=True`.
- BE: установить `BE_PCT=1.1`; `BE_PCT=0.0` отключает BE.
- 4h режим: `ENABLE_4H_BULL_REGIME_FILTER=True` требует `previous_4h_return >= 0`. Выключен по умолчанию, чтобы не смешивать эксперименты.
- SHORT-кандидаты: `ENABLE_SHORT_SIGNALS=True` включает экспериментальные независимые SHORT-условия. По умолчанию выключены; это гипотеза для исследования, не подтверждённая стратегия. Сравни отдельно и не смешивай результаты с LONG до проверки.

## Важные ограничения

- R1 breakout/retest работает только когда в поле `in_zone` есть разборчивая метка `R1[xx.xk-yy.yk]`. Для иных форматов сигнал в R1 блокируется безопасно.
- Фильтры momentum и R1 могут заметно уменьшить количество сделок. Сравнивай не только winrate, но и количество сделок, чистый PnL, максимальную просадку и результат на отдельном временном участке.
- BE stop на цене входа не означает чистый ноль: комиссия входа и выхода остаётся в `net_pnl_pct`.
- Бэктест требует доступа к Binance Futures API для загрузки 1m свечей. Если сети нет, полный результат здесь не был пересчитан.
